## 사용자가 달라지는 점

국회도서관 `/basic` 검색은 그대로 사용합니다. 제목·저자·발행처에 있는 HTML 표시 태그를 정리하고, `기사명/저자명` 등 대체 제목 필드를 읽습니다. 공식 자료유형·확인된 관리번호 패턴·명시된 학위/수록정보로 분류한 뒤 **학위논문 → 학술기사 → 도서자료 → 미확인** 순으로 보여줍니다.

일반 자료가 나왔다는 이유로 원래 검색어를 몰래 넓히지 않습니다. 기본값은 원검색만 사용하며, 선택 설정으로 허용했더라도 API가 실제 0건일 때에만 재검색합니다. 서로 다른 검색어의 결과는 합치지 않습니다.

분류 근거가 있는 자료는 사용자 확인 없이 표시합니다. 모든 자료를 직접 분류하는 이전 폼은 제거했습니다. 근거 부족/충돌은 미확인 영역에만 남깁니다. 제목·유형 누락이 있을 때 공개 상세정보 보완을 검색당 최대 5건 시도하며, 차단·로그인·접근 정책 미확인 시 중단합니다.

다음 페이지 수집 중 오류가 나면 성공한 앞 페이지를 유지하고 실패한 페이지부터 재시도합니다. 원본 API 순번을 보존하며, 공식 웹사이트 관련도와 같다고 단정하지 않습니다. `API 검색 진단`에서 동일 조건 및 관리번호 표본을 비교할 수 있습니다.
